- storage-layer / multicall-cli: Sprint 19 (2026-08-17) — durable storage, T2.3 → done, Layer 2 closed (**Q29**): `crates/storage/src/sqlite/` adds `SqliteStorage` on libsql 0.9 core-only (local-file; NO remote/replication/sync/tls compiled in; libsql is a hard requirement — rusqlite+spawn_blocking fallback explicitly rejected). Kine-style append-only `kv` event table (row `id` = global revision, key, value JSON TEXT, create_revision, prev_revision, deleted, explicit `version` — a COUNT-derived `version` shrank after compaction, fixed mid-sprint) + `meta` table (schema_version/revision/compact_revision); PRAGMAs WAL + synchronous=FULL + busy_timeout=5000ms; revision restored at open from max(meta.revision, MAX(kv.id)). CRUD+CAS in `BEGIN IMMEDIATE` tx; broadcast (cap 1024, WATCH_CAP parity) strictly post-COMMIT under one connection mutex; watch replay = `SELECT id >= start ORDER BY id` (survives restart); compact keeps latest-row-per-key, watermark persisted, watch at/below → `Compacted` (410 Gone). Contract parity: 26 embedded tests extracted to `tests/contract/` — 26 portable cases run against BOTH backends via `storage_contract!` (1 embedded-only history-eviction case stays; the 26th shared case is the post-review unrepresentable-start-revision pin); +5 file-backed durability tests +8 unit (incl. tx self-heal + failed-COMMIT pins). Post-review hardening: write/compact entry self-heals a leftover open transaction (`is_autocommit` + ROLLBACK) so an aborted write or failed COMMIT cannot poison the single connection until restart; replay clamps `Revision > i64::MAX` instead of wrapping negative (whole-log replay). cli: `--datastore-endpoint` wired — empty/None keeps `EmbeddedStorage` default (Q17 opt-in), `sqlite://<path>` → SqliteStorage, foreign schemes fatal (pure `classify_dsn`, +3 unit); `--kine-tls`/`datastore-*` stay noops (§C.6). Scripts: `local-up.sh` boots `sqlite://$DD/server/state.db`; NEW `durability-e2e.sh` D1–D4 (boot+seed / SIGTERM drain / restart with identical resourceVersions / revision continuity + watch replay + controller resync) in CI. +43 tests (674 → 717); Cargo.lock +31 packages (libsql core), caret-only.
